📝 Usage Instructions

  1. Choose a widget type: rates, converter, or chart
  2. Select currency: Add ?currency=USD (or any supported currency code)
  3. Copy the iframe code and paste it into your HTML
  4. Customize dimensions: Adjust width/height as needed
  5. Auto-refresh: Widgets update every 60 seconds automatically
