# OneSignal Setup Guide for NairaMet

## 📱 What is OneSignal?

OneSignal is a push notification service that sends instant alerts to users' browsers and mobile devices. Unlike emails (which use HTML templates), push notifications are **text-only** with a title, message, and icon.

## 🔧 Setup Instructions

### Step 1: Create OneSignal Account

1. Go to [https://onesignal.com](https://onesignal.com)
2. Sign up for a free account
3. Click "New App/Website"
4. Name it "NairaMet"

### Step 2: Configure Web Push

1. Select **"Web Push"** as the platform
2. Choose **"Typical Site"** (not WordPress)
3. Enter your site details:
   - **Site Name**: NairaMet
   - **Site URL**: `https://nairamet.com`
   - **Default Icon URL**: `https://nairamet.com/Nairamet.svg`
   - **Auto Resubscribe**: Enable (recommended)

### Step 3: Get Your Credentials

After setup, you'll get:
- **App ID**: Found in Settings → Keys & IDs
- **REST API Key**: Found in Settings → Keys & IDs

### Step 4: Add to Environment Variables

Add these to your `.env.local`:

```bash
# OneSignal Configuration
NEXT_PUBLIC_ONESIGNAL_APP_ID=your_app_id_here
ONESIGNAL_REST_API_KEY=your_rest_api_key_here
```

### Step 5: Configure Allowed Origins

In OneSignal Dashboard:
1. Go to Settings → All Browsers
2. Add these origins:
   - `https://nairamet.com`
   - `http://localhost:3000` (for testing)

### Step 6: Test Push Notifications

1. Visit your site: `https://nairamet.com/alerts`
2. Click "Enable Push Notifications"
3. Allow notifications in your browser
4. Click "Test" button to send a test notification

## 📋 How It Works

### Email vs Push Notifications

| Feature | Email (Resend) | Push (OneSignal) |
|---------|---------------|------------------|
| **Format** | HTML with styling | Text only |
| **Template** | Custom branded HTML | Title + Message |
| **Delivery** | Email inbox | Browser/device notification |
| **Limit** | 1 per month | Unlimited |
| **Setup** | Resend API key | OneSignal App ID |

### Push Notification Format

**Example notification:**
```
Title: 📈 USD/NGN Above ₦1,620
Message: Black Market rate now at ₦1,645 (+1.5%)
```

**What users see:**
- Desktop: Small notification popup in corner
- Mobile: Standard push notification
- Clicking opens: `/alerts` page

## 🎨 Customization

### Notification Content

The push notification template is in `lib/push-notification-template.ts`:

```typescript
{
  title: "📈 USD/NGN Above ₦1,620",
  message: "Black Market rate now at ₦1,645 (+1.5%)",
  subtitle: "Your rate alert has been triggered",
  icon: "/Nairamet.svg"
}
```

### Notification Types

1. **Rate Alerts** - When threshold is reached
2. **Test Notifications** - When user clicks "Test"
3. **Welcome Notifications** - When user first subscribes

## 🔍 Testing

### Local Testing

1. Start dev server: `npm run dev`
2. Visit: `http://localhost:3000/alerts`
3. Enable push notifications
4. Create a rate alert
5. Manually trigger by changing rates

### Production Testing

1. Deploy to Vercel
2. Visit: `https://nairamet.com/alerts`
3. Enable push notifications
4. Create alert and wait for trigger

## 🚨 Troubleshooting

### "Push notifications not supported"
- Use Chrome, Firefox, or Edge (Safari has limited support)
- Ensure HTTPS (required for push notifications)
- Check browser permissions

### "Failed to subscribe"
- Verify OneSignal App ID is correct
- Check allowed origins in OneSignal dashboard
- Clear browser cache and try again

### "Notification not received"
- Check browser notification permissions
- Verify REST API key is correct
- Check OneSignal dashboard for delivery status

## 📊 Monitoring

### OneSignal Dashboard

View in OneSignal:
- **Delivery Reports**: See how many notifications were sent
- **User Segments**: Track subscribed users
- **Message History**: View all sent notifications

### NairaMet Dashboard

View in your app:
- **Monitoring Dashboard**: `/alerts` page
- **Alert History**: Track triggered alerts
- **Subscription Status**: See if user is subscribed

## 💡 Best Practices

1. **Keep messages short** - Push notifications have character limits
2. **Use emojis** - Makes notifications more noticeable (📈📉🔔)
3. **Include key info** - Currency, rate, and change percentage
4. **Test regularly** - Use the test button to verify delivery
5. **Monitor delivery** - Check OneSignal dashboard for issues

## 🔐 Security

- **REST API Key**: Keep secret, never expose in client code
- **App ID**: Public, safe to use in client code
- **User IDs**: Generated by OneSignal, stored locally
